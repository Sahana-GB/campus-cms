- The AI first built against a temporary stand-in for `Session`. Person A's real API was different, so I replaced it with `Session.getInstance()` and fixed the compile errors.
- Some instructions had to be corrected as we went: a launch command that did not match our project (I used `scripts/run.sh` instead), and cleanup commands that ran before a pull request was merged (I checked the branches on GitHub and merged the pull requests properly).
- CGPA is currently computed as the credit-weighted average of each course percentage divided by 10 (not letter-grade bands), and it is 0 when a student has no published grades. This is explained in my report section.
